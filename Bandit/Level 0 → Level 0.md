# Level 0 → Level 0

```bash
[liveuser@blackarch]-[~]
>>> ssh -p 2220 bandit0@bandit.labs.overthewire.org
```

---

**`ssh`** – Secure Shell command for remote login

**`-p 2220`** – Specifies the connection port (2220 instead of the default 22)

**`bandit0@bandit.labs.overthewire.org`** – Connects as user `bandit0` to the `bandit.labs.overthewire.org` server
